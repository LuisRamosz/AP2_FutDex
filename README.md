# FutDex ⚽

# Sobre o projeto

O FutDex é um aplicativo Android desenvolvido como projeto acadêmico do curso de Análise e Desenvolvimento de Sistemas. Seu objetivo é apresentar um catálogo de clubes de futebol, permitindo visualizar uma lista de equipes e consultar informações detalhadas sobre cada clube.

# Funcionalidades

- Listagem de clubes de futebol.
- Exibição dos escudos dos clubes.
- Navegação entre a lista e a tela de detalhes.
- Consulta de país, ano de fundação, estádio, liga, categoria e descrição dos clubes.

# Tecnologias utilizadas

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- Navigation Compose
- Coil para carregamento de imagens

# Como executar

1. Clone ou baixe este repositório.
2. Abra o projeto no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Execute o aplicativo em um emulador ou dispositivo Android compatível.
